# FirstTrace Public Eval Fixtures

These eval cases are intentionally generic. They cover the manager-owner triage
bug shapes requested for the next version without embedding private customer
routes, product nouns, repositories, tenants, channels, or workflow labels.

Run them from the repository root with:

```bash
firsttrace eval --config examples/minimal.local.config.yaml --cases examples/evals/manager-owner-triage.yaml
```
